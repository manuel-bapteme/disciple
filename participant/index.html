📘 Participant

Mes réponses

Vos réponses et vos enregistrements restent uniquement sur cet appareil. Pour les montrer à la personne qui vous accompagne, enregistrez un fichier et envoyez-le-lui, ou partagez votre écran pendant la visio (en partageant aussi le son).

Comment ça marche ?

🔊 Écouter : l’appareil lit la question, le texte ou le verset à voix haute. Touchez une seconde fois pour arrêter. La vitesse se règle en haut de l’écran.

📖 Références : touchez une référence pour afficher le texte biblique et l’écouter.

Pour répondre, choisissez ce qui vous convient le mieux :

  • Écrire dans la zone de réponse, ou utiliser le micro du clavier de votre téléphone, tablette ou ordinateur.
  • 🎙 Dicter : vous parlez, le texte s’écrit dans la zone choisie. S’il y a des erreurs, ce n’est pas grave : vous les corrigerez avec la personne qui vous accompagne.
  • ⏺ M’enregistrer : votre voix est gardée telle quelle. La personne qui vous accompagne l’écoutera avec vous.
  • Pour certaines questions, il suffit de toucher une réponse (Oui, Pas encore…).

Confidentialité. Les réponses et les enregistrements restent sur cet appareil, rien n’est envoyé sur internet. Seul le bouton « Dicter » utilise le service de reconnaissance vocale du navigateur : avec Chrome ou Edge, la voix est transmise à Google ou Microsoft pour être transcrite. Si vous préférez que rien ne sorte de l’appareil, utilisez « M’enregistrer ».
